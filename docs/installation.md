# Установка Just для себя

## Быстрый запуск Windows

Распаковать целиком `releases/0.1.1/just-windows.zip` в любую обычную папку и запустить `day_planner.exe`. DLL и каталог data должны оставаться рядом. Приложение начинает с пустого списка; интернет для задач не нужен. Нужные библиотеки VC runtime входят в архив рядом с EXE ([рекомендация Flutter](https://docs.flutter.dev/platform-integration/windows/building)).

Данные сохраняются в каталоге поддержки приложения Windows (`%APPDATA%/Didje/Day` после определения через path_provider). Внутренние имя EXE, каталог данных и идентификатор пакета сохранены при переименовании в Just, чтобы прежние данные оставались доступны. Для отдельного тестового экземпляра: `day_planner.exe --data-directory "C:\папка\отдельного\набора"`. Не запускать два процесса с одним файлом базы.

В настройках доступны тема, звук, громкость, экспорт и импорт JSON. Перед импортом показываются количества и создаётся копия предыдущих данных. Копии в каталоге backups рядом с базой. Файл экспорта не содержит ключа синхронизации.

## MSIX и напоминания Windows

MSIX подписан личным самоподписанным сертификатом. Скрипт сборки не устанавливает его в доверенные и не меняет системные хранилища сертификатов. Если нужна установленная версия с напоминаниями, проверить SHA256 по SHA256SUMS.txt и сертификат day-signing.cer, затем явно установить публичный сертификат в «Доверенные люди» и открыть just-windows.msix. Это действие выполняет пользователь. Папка `.tools/signing` содержит закрытый ключ и пароль для будущих обновлений; не отправлять её и не добавлять в Git.

ZIP сообщает, что для напоминаний нужна MSIX-версия. После установки MSIX необходимо отдельно проверить выдачу, перенос времени, отмену и уведомление после закрытия приложения. Do Not Disturb/Focus Assist ещё не проверены. Отключение звука в настройках приложения действует независимо от этих проверок. Ошибки постановки и отмены напоминаний видны на главном экране, а после повторного запуска проверяются снова. Windows дополнительно проверяет доступность уведомлений через [ToastNotifier.Setting](https://learn.microsoft.com/en-us/uwp/api/windows.ui.notifications.toastnotifier.setting).

## Подключение второго устройства

Нужен собственный доступный HTTPS сервер. [Запуск сервиса](../server/README.md). В настройках приложения ввести адрес вида `https://ваш-сервер/sync` и ключ. Сначала выполняется пустая проверка; задачи не отправляются до выбора «Объединить» или «Открыть отдельно». Оба варианта сохраняют резервную копию и прежний файл базы.

Ключ хранится в защищённом хранилище ОС. При конфликте нажать статус синхронизации внизу экрана и выбрать локальную или серверную версию; перед выбором сохранится копия. Отключение синхронизации не удаляет локальные задачи. До размещения сервера доступность через VPN не доказана. Текущие интеграционные проверки использовали две независимые базы и локальный сервер на одном компьютере.
