# Визуальные ориентиры приложения

Актуальные выбранные пользователем источники, карта иконок, пружинные отклики и рецепт FLOW: [Just — иконки, движение и приветствие](ui-motion-and-rose-gold.md).

Оригинальные файлы выбраны из локальной библиотеки `Design Reference Library`. Номера соответствуют её `INDEX.jsonl`. Имя отправителя Telegram само по себе не подтверждает авторство макета.

| Файл | Что берём | Как адаптируем |
| --- | --- | --- |
| REF-0547 | Ясные строки, небольшие отметки и компактную навигацию по дням | Вместо большой карточки каждой привычки используем более плотные строки обычных дел. |
| REF-0537 | Мягкие голубые и тёплые жёлтые акценты, свободное пространство | Применяем к одному главному списку; социальную карту из референса не переносим. |
| REF-0819 | Небольшой эмоциональный персонаж и видимые метки повтора и времени | Персонаж появляется в пустом или завершённом состоянии и не занимает половину рабочего экрана. |
| REF-0559 | Хорошую различимость активного дня и заметное главное действие в тёмной теме | Уменьшаем насыщенность и высоту карточек для ежедневного списка из многих задач. |

Анимация и звук не установлены по статичным изображениям. Они описаны отдельно в спецификации. Референсы задают отдельные визуальные приёмы; интерфейс собирается в единую систему под Windows и Android.


Сами изображения референсов взяты из личной библиотеки и в публичный репозиторий не входят.
