## Принятые решения и цена ошибки

В хронологическом порядке из журналов выполнения:

1. Вместо недоступных в sandbox Bash помощников использованы PowerShell briefs/ledger с теми же границами задач. Цена: записи помощников поддерживаются напрямую.
2. Envelope проверяется целиком, невалидная отдельная операция получает rejected ACK. Это обеспечивает частичный успех протокола. Цена: HTTP 200 не означает принятие каждой операции; клиент обязан читать ACK.
3. Flutter запускается через существующий короткий Windows 8.3 путь из-за сбоя native hooks на пробелах. Цена: на системах без 8.3 нужен SDK в пути без пробелов.
4. Drift хранит протокольные JSON snapshots через параметризованный SQL и явную миграцию, без generated table DTO/build_runner. Цена: изменения SQL колонок требуют отдельной проверки миграции.
5. Локальные junctions заменяют глобальное включение Developer Mode. Цена: на чистом checkout wrapper должен восстановить ссылки плагинов.
6. Обе операции подключения сначала создают новую БД, затем меняют bootstrap pointer. Прежние дела и очередь сохраняются при сбое. Цена: исторические базы занимают дополнительное место.
7. Для IANA/DST расчётов сервера добавлен Temporal polyfill. Цена: две небольшие npm зависимости вместо собственного преобразования зон.
8. Если сервер отменил повтор, отредактированные предсказанные потомки становятся отдельными обычными делами с новыми id и сообщением в UI. В неоднозначном случае важнее сохранить написанное. Цена: эти восстановленные дела больше не продолжают прежний повтор.
9. В протокол v1 добавлено expectedWorkspaceId для подключённых обменов. Цена: клиент и сервер этого выпуска нужно обновлять вместе; более старый сервер отклонит неизвестное поле.

Отложенные reviewer области рассмотрены отдельно:

10. Android оставлен в исходниках, без APK и принятия SDK лицензии, по прямому решению пользователя. Цена: на телефоне этой версией пока пользоваться нельзя.
11. Доверие сертификату и установка MSIX не выполнялись автоматически: это изменение системного доверия. Цена: доставка уведомлений после закрытия/перезагрузки ещё не доказана.
12. Реальный HTTPS/VPN обмен не заявлен работающим: доступный сервер не развёрнут и телефон не подключён. Цена: сейчас доказан обмен двух независимых БД через локальный сервер, а не двух физических устройств.
