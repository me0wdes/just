# Напоминания и отклик

Планируются одноразовые уведомления текущих экземпляров задач. Повтор создаёт следующий экземпляр с новым UTC моментом из локального времени правила и IANA зоны. Сервер использует Temporal, клиент — timezone. Москва и переход DST New York проверены автоматическими тестами. Закрытое приложение не синхронизирует новые удалённые изменения: уже поставленные уведомления отражают последнее известное состояние.

Windows ZIP без package identity сообщает, что для напоминаний нужна MSIX-версия. Это не выдаётся за работающее управление уведомлениями. Подписанный MSIX требует явной установки доверия личному сертификату. Уведомления после закрытия, отмена показанных уведомлений и режим Do Not Disturb требуют отдельной проверки установленной версии.

Звук completion 110 мс, undo 90 мс, создан математически из синусоид с плавной огибающей; исходник tools/generate_sounds.py. Он вызывается только после успешной локальной команды пользователя; удалённый обмен не вызывает CompletionFeedback. Настройки отключения и громкости проверены. Windows адаптер SHQueryUserNotificationState учитывает присутствие/презентацию/quiet time. Этот API не доказывает соответствие современным Focus Assist / Do Not Disturb; реальная проверка этих режимов пока NOT VERIFIED. До проверки звук можно отключить в настройках приложения.

Android код содержит permissions, receivers восстановления и проверку ringer mode. SDK лицензия не принята, APK и поведение Android отложены пользователем. Никаких заявлений о проверке телефона или перезагрузки нет.
