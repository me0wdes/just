## macOS

Платформа `app/macos` добавлена 20 октября 2026. Окно без серой полосы заголовка: кнопки окна лежат поверх фона, верхняя полоса 30 px перетаскивает окно, двойной клик разворачивает. Минимальный размер окна 760×560, положение запоминается. Шорткаты ⌘N и ⌘F. Ключ синхронизации хранится в login keychain, поэтому для локальной сборки не нужна команда разработчика. Разрешения песочницы: сеть-клиент для синхронизации, выбранные пользователем файлы для копий. Напоминания через Notification Center; разрешение спрашивается при первом напоминании.

Сборка только на Mac с Xcode и Flutter: `tools/build-macos.sh`. Готовый архив — `releases/<версия>/Just-<версия>-macOS.zip`. Иконка пока стандартная Flutter, её нужно заменить в `app/macos/Runner/Assets.xcassets/AppIcon.appiconset`.
