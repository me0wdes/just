**Windows:** `Just-Setup-….exe`, права администратора не нужны. **macOS:** откройте `.dmg` и перетащите Just в «Программы». **Android:** откройте `.apk` на телефоне. Сборки пока без подписи магазинов: Windows и macOS спросят подтверждение при первом запуске. Новые версии Just предлагает сам.

## Что умеет

Задачи на сегодня и все задачи, свои списки с иконками, сроки с временем или без, повторы и напоминания, светлая и тёмная темы, звуки и анимации. Данные хранятся на устройстве. Синхронизация между устройствами — через [свой сервер](docs/self-hosting.md), он ставится одной командой. Сервер можно поделить с семьёй или друзьями: у каждого свои задачи, чужие не видны.
