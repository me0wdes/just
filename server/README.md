# День Sync

Node.js >=24. В папке server выполнить `npm ci`, затем `npm test`. Сервис слушает только 127.0.0.1; данные по умолчанию в `day-data/sync.sqlite` (не коммитить).

Создать ключ явной командой `node src/index.mjs --generate-token`, сохранить в менеджер паролей и передать через переменную окружения DAY_SYNC_TOKEN. Обычный запуск ключ не показывает. Затем `node src/index.mjs --data <папка> --port 18766`.

POST /sync принимает протокол [v1](../contracts/sync-v1.md). Пустой запрос возвращает workspaceId и изменения; проверка соединения не должна отправлять задачи до согласования пространства.

Для телефона необходим собственный доступный HTTPS адрес с доверенным TLS сертификатом. TLS завершается прокси на том же хосте, proxy_pass направлен на loopback:18766; HTTP порт напрямую наружу не открывать. Размещение и проверка с реальным VPN пока не выполнены.

Резервная копия активной базы: `await store.backupTo(path)` из store.mjs, через SQLite backup API с WAL. Для восстановления остановить сервис, сохранить текущий каталог целиком и открыть проверенную копию вместо основной базы. Не заменять один файл .sqlite у работающего процесса. Подтверждения операций и tombstones хранятся без срока удаления; включены в backup.

В логах процесса только запуск/ошибка запуска; HTTP logger получает event/status без ключа, URL параметров, названий и заметок. SQLite файл содержит личные данные в открытом виде; защиту диска обеспечивает ОС.
